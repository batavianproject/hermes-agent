# Resemble Detect Skill

This skill provides the ability to detect AI-generated content (deepfakes) and perform media intelligence analysis using the Resemble AI platform. It allows Hermes to identify synthetic manipulation in audio, images, video, and text.

## 🎯 Core Capabilities

### 1. Deepfake Detection
- **Multimodal Analysis:** Detect AI-generated audio, images, and video.
- **Results:** Provides labels (`ai` or `human`), confidence scores, and status visualizations.
- **Source Tracing:** Identify specific AI platforms (e.g., ElevenLabs, Resemble) that may have synthesized the audio.

### 2. Media Intelligence
- **Speaker Analysis:** Extract speaker identity, emotion, and transcription.
- **Content Analysis:** Detect misinformation signals, abnormalities, and analyze image/video context.
- **Interactive Querying:** Ask natural-language follow-up questions about completed detection results.

### 3. Text & Agent Detection
- **Text Analysis:** Determine if essays, emails, posts, or comments were generated by an AI model.
- **Agent Detection:** Identify whether website traffic originates from human users or AI agents.

## 🛠️ Workflow & API Usage

Hermes should follow these operational steps:
1. **Submission:** Submit media via URL or direct file upload to the `POST /detect` endpoint.
2. **Polling:** If the result is `processing`, poll the status until it is `completed`.
3. **Analysis:** Once completed, analyze the `prediction` and `confidence` fields.
4. **Verdict:** Deliver the result based on the API output.

## ⚠️ THE IRON LAW (Operational Constraint)
**"NEVER DECLARE MEDIA AS REAL OR FAKE WITHOUT A COMPLETED DETECTION RESULT."**

- **No Speculation:** Do not guess, infer, or speculate about media authenticity.
- **Evidence-Based:** Every claim must be backed by a completed Resemble detect job with a returned `label`, `score`, and `status: "completed"`.
- **No Substitutions:** If a detection fails, report the failure; do not substitute the AI's judgment for the API's result.

## 🧰 Available Endpoints
- **Detect:** Main deepfake analysis.
- **Intelligence:** Detailed media metadata and forensics.
- **Detect Intelligence:** Natural language querying of results.
- **Text Detection:** AI-generated text verification.
- **Agent Detection:** Website traffic analysis.
